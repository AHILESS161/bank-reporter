# Архитектура Bank Reporter

Запрос из веб-чата создает `AnalysisRun`. Celery worker выбирает валидированный workflow, передает оркестрацию DeepSeek V4.1 Flash и выполняет только зарегистрированные skills. Финансовую интерпретацию выполняет Ling 3.0 Flash Fin с fallback на DeepSeek. Числовые расчеты выполняет Python-код с `Decimal`; каждая цифра связывается с `ProvenanceRef`.

## Skills и workflows

`app/skills` — единая граница расширения агента:

- `contracts.py` описывает версионированные манифесты, права, side effects, model policy и MCP binding;
- `registry.py` валидирует вход через Pydantic и одинаково исполняет локальные, service-backed и MCP skills;
- `catalog.py` регистрирует банковские возможности и генерирует tool schemas для модели;
- `workflows.py` проверяет зависимости, запрещает циклы, маршрутизирует запрос и формирует допустимую цепочку для оркестратора.

Встроенные сценарии: поиск отчетности, поиск публикаций и проверяемый финансовый анализ. Пользовательские линейные workflow сохраняются из раздела «Конструктор» в `IntegrationState`; при совпадении фразы-триггера агент получает их как маршрут выполнения.

MCP используется на внешней границе. Для MCP skill нужен тот же `SkillManifest`, `MCPBinding(server, tool)` и реализация `MCPInvoker`. Внутренние расчеты, чтение PostgreSQL и создание файлов остаются локальными вызовами без сетевых накладных расходов.

API конструктора:

- `GET /api/skills` — каталог контрактов;
- `GET /api/workflows` — встроенные и пользовательские графы;
- `POST /api/workflows/validate` — проверка ссылок и циклов без запуска;
- `PUT /api/workflows/{id}` и `DELETE /api/workflows/{id}` — управление пользовательскими схемами.

Источники обрабатываются в порядке доверия: официальный сайт банка, Банк России, Минфин, доверенные деловые СМИ, остальные публичные страницы. Browser service изолирует Chromium и не предоставляет модели shell либо произвольный JavaScript.

## Границы MVP

- Нет регистрации, multi-tenant режима, платежей и закрытых источников.
- Нет обхода CAPTCHA/paywall и автоматического входа в аккаунты.
- Документы загружаются по запросу; постоянный мониторинг действует только для watchlist.
- Web доступен только на `127.0.0.1:3000`.

## Данные

PostgreSQL хранит метаданные, сообщения, события, финансовые факты и журнал происхождения. `/data` хранит неизменяемые версии оригиналов и сформированные HTML/PDF/PNG/CSV/XLSX. Удаление документа также удаляет принадлежащие ему файлы, но выполняется только по явному запросу пользователя.
