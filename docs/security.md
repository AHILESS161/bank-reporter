# Безопасность

## Модель угроз

Приложение обрабатывает недоверенные PDF, таблицы, архивы, HTML-страницы и ответы поисковиков. Главные риски: prompt injection, SSRF, redirect на внутренний адрес, вредоносный/ложный MIME, ZIP bomb, oversized upload, произвольное действие браузера, утечка ключей и публикация локального приложения без auth.

## Сетевые запросы

- принимаются только `http` и `https` URL;
- hostname разрешается до запроса;
- private, loopback, link-local и служебные адреса запрещены;
- redirects проверяются повторно;
- фактический peer IP сверяется;
- размер ответа ограничен;
- блокировки, CAPTCHA, paywall и login не обходятся.

Не добавляйте домен в allowlist, если он может перенаправлять на пользовательский/private URL без повторной проверки.

## Browser action policy

Разрешены поисковые формы, навигация, чтение, поиск текста, download и локальный render. Запрещены:

- авторизация и отправка паролей;
- платежи и торговые операции;
- изменение данных на внешних сайтах;
- upload на внешние сайты;
- arbitrary remote eval;
- `agent-browser chat` и передача браузеру свободной агентской власти.

Browser-worker находится во внутренней Compose-сети и не публикует порт на host.

## Prompt injection

Содержимое страницы или документа всегда включается как недоверенные данные. Инструкции внутри источника не могут менять system policy, список tools, лимиты, модель или права. Профессиональные отчёты используются как контекст, а не как инструкции и не как автоматический источник первичных чисел.

## Загрузки и архивы

- upload endpoint принимает PDF, XLSX, CSV, DBF и ZIP;
- проверяются расширение, фактический MIME, сигнатура и SHA-256;
- лимит файла по умолчанию 100 МБ;
- лимит распакованного архива 500 МБ;
- абсолютные пути, `..`, symlink и чрезмерное сжатие запрещаются;
- OCR запускается только при необходимости, а не по команде из документа.

## Достоверность данных

`FinancialFact` хранит Decimal, валюту, масштаб, период и `ProvenanceRef`. Расчёты выполняет код. Отчёт не должен содержать уверенное число без источника. Контекст из СМИ маркируется по trust tier. Если обе модели не прошли проверку, сохраняется частичный результат с причиной.

## Предпросмотр артефактов

PDF отдаётся inline с `nosniff`, `frame-ancestors 'self'` и `no-store`. HTML-отчёт получает CSP:

```text
default-src 'none'; style-src 'unsafe-inline'; img-src data:;
font-src data:; base-uri 'none'; form-action 'none'; frame-ancestors 'self'
```

Внешние скрипты и произвольный JavaScript модели не выполняются. Зависимости и шрифты отчёта должны быть встроены.

## Секреты и данные

- `.env` не должен попадать в Git и backup общего доступа;
- API не возвращает значение ключа;
- нет внешней аналитики или телеметрии;
- PostgreSQL и `/data` содержат чаты, документы и отчёты — доступ к backup ограничивается;
- логировать API headers, cookies и полный секрет запрещено.

## Граница localhost

Compose публикует только `127.0.0.1:3000`. Это важная часть защиты, потому что в MVP нет регистрации и ролей. На удалённом сервере используйте SSH-туннель. Публичный reverse proxy без отдельной аутентификации и HTTPS — небезопасная конфигурация.

## Остаточные риски

- single-user приложение не изолирует данные разных людей;
- сторонний источник может публиковать ложные цифры;
- OCR может ошибиться, поэтому scan-derived факты требуют проверки;
- нет malware sandbox для содержимого документов;
- нет high availability и централизованного secret manager;
- SQLAlchemy `create_all` не заменяет безопасную систему миграций;
- локальный администратор Docker имеет доступ к volumes и секретам контейнера.
