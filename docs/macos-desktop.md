# Bank Reporter Desktop для macOS

Desktop-редакция предназначена для пользователя с Mac на Apple Silicon, которому не нужны Docker, Git, PostgreSQL и Redis. Она поставляется как обычный ARM64 DMG.

## Установка готовой версии

1. Откройте раздел **Releases** репозитория.
2. Для Mac с M1/M2/M3/M4 и новее скачайте файл с `arm64` в названии.
3. Откройте DMG и перетащите **Bank Reporter** в **Applications**.
4. Первый раз откройте приложение правой кнопкой → **Открыть**. Текущая сборка не подписана сертификатом Apple Developer.
5. Перейдите в **Настройки**, вставьте адрес API и ключ RouterAI, затем нажмите **Сохранить настройки** и **Проверить подключение**.

Приложение поднимает три локальных процесса только на `127.0.0.1`: интерфейс, API и защищенный browser-worker. Они завершаются вместе с приложением.

## Где находятся данные

Чаты, SQLite, документы, отчеты, настройки и журналы располагаются в:

```text
~/Library/Application Support/Bank Reporter/
```

Секреты находятся в `data/runtime-settings.json`. API не возвращает сохраненные токены в браузер. Не публикуйте и не пересылайте этот каталог.

## Что заменено по сравнению с Docker

| Docker-редакция | Desktop-редакция |
|---|---|
| PostgreSQL | SQLite |
| Redis + Celery worker | встроенная очередь из двух потоков |
| Celery Beat | встроенный планировщик |
| отдельный Node-контейнер | локальный browser-worker |
| браузер по адресу localhost | окно приложения Electron |

Финансовые расчеты, provenance, skills, workflows и модели остаются общими.

## Уведомления Telegram

1. В Telegram откройте `@BotFather`.
2. Отправьте `/newbot`, задайте имя и username.
3. Скопируйте выданный токен и вставьте его в **Настройки → Telegram**.
4. Нажмите **Сохранить настройки**.
5. Откройте созданного бота, нажмите **Start** или отправьте `/start`.
6. Вернитесь в Bank Reporter и нажмите **Найти Chat ID**.
7. Нажмите **Отправить тест**.

Бот отправляет утренний дайджест в 08:00 МСК, напоминания за 24 часа и сообщения о найденной ожидаемой публикации. Команды: `/today`, `/week`, `/mute`, `/unmute`. В Desktop-редакции приложение должно быть запущено, иначе локальный планировщик не работает; пропущенные интервальные уведомления задним числом не отправляются.

## Автоматическая сборка DMG

Workflow `.github/workflows/build-macos-desktop.yml` запускается вручную либо при теге `desktop-v*`. Он собирает ARM64 DMG на нативном Apple Silicon runner. При запуске по тегу файл автоматически добавляется в GitHub Release.

Пример выпуска:

```bash
git tag desktop-v0.2.0
git push origin desktop-v0.2.0
```

Для локальной сборки на Mac нужны Node.js 24 и Python 3.12:

```bash
bash scripts/build-macos-desktop.sh
```

Результат появится в `apps/desktop/dist`.

## Ограничения первой Desktop-сборки

- сборка пока не подписана и не нотарифицирована Apple;
- OCR требует доступного бинарного файла Tesseract; текстовые PDF, XLSX, CSV и DBF работают без него;
- уведомления и календарный мониторинг выполняются, только пока приложение запущено;
- DMG собирается на GitHub Actions, а не на Windows-машине разработчика.
